# Canva Design Types Reference

## Supported design_type values

| Type | Use case | Typical size |
|------|----------|-------------|
| `instagram_post` | Instagram feed post | 1080×1080 |
| `your_story` | Instagram/Facebook Stories | 1080×1920 |
| `facebook_post` | Facebook feed post | 940×788 |
| `facebook_cover` | Facebook page cover | 820×312 |
| `twitter_post` | X/Twitter post | 1600×900 |
| `pinterest_pin` | Pinterest pin | 1000×1500 |
| `youtube_thumbnail` | YouTube video thumbnail | 1280×720 |
| `youtube_banner` | YouTube channel art | 2560×1440 |
| `linkedin_banner` | LinkedIn banner (use `facebook_cover`) | 1584×396 |
| `presentation` | Slides (**use Presentation Flow!**) | 1920×1080 |
| `poster` | Print poster | A2/A3 |
| `flyer` | Print flyer | A5/A4 |
| `business_card` | Business card | 3.5×2 in |
| `logo` | Logo design | 500×500 |
| `invitation` | Event invitation | various |
| `postcard` | Postcard | 6×4 in |
| `infographic` | Long-form infographic | 800×2000+ |
| `resume` | CV/Resume | A4 |
| `doc` | Canva Doc (rich text) | — |
| `document` | Document layout | A4 |
| `report` | Multi-page report | A4 |
| `proposal` | Business proposal | A4 |
| `card` | Greeting card | various |
| `photo_collage` | Photo collage | various |
| `desktop_wallpaper` | Desktop background | 1920×1080 |
| `phone_wallpaper` | Phone background | 1080×1920 |

## Quick lookup by platform

**Instagram:** `instagram_post` (feed), `your_story` (stories/reels cover)
**Facebook:** `facebook_post` (feed), `facebook_cover` (page header)
**YouTube:** `youtube_thumbnail`, `youtube_banner`
**X/Twitter:** `twitter_post`
**Pinterest:** `pinterest_pin`
**LinkedIn:** use `facebook_cover` or custom resize
**Print:** `poster`, `flyer`, `business_card`, `postcard`
**Documents:** `doc`, `document`, `report`, `proposal`, `resume`

## Notes

- `presentation` MUST go through the Presentation Flow (outline review first)
- For LinkedIn posts, `twitter_post` (1600×900) works well as alternative
- For custom sizes not in this list, create any type then use `resize-design` with custom dimensions
